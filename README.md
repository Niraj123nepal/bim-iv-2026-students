# Class Profile Git Exercise

A small classroom website for practicing Git commands with student profile pages.

## Student workflow

1. `git clone <repository-url>`
2. `git checkout -b student-01`
3. Copy `students/student-template.html` to `students/student-01.html`
4. Update the student name / number in the new file
5. `git add .`
6. `git commit -m "Add student 01 profile"`
7. `git push -u origin student-01`

## Notes

- Keep the pages simple.
- Only edit the HTML file in `students/` for your own profile.
- Do not add extra sections like email, phone, or social links.
